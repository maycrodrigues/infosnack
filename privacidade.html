Política de Privacidade

Vigente desde 19 de outubro de 2026

Resumo: o app InfoSnack só acessa as contas oficiais do canal, guarda o mínimo para publicar os vídeos, mantém tudo no computador da equipe e não vende nem compartilha dados. Este site não usa cookies nem rastreamento.

1. Quem somos

O InfoSnack é um canal de notícias em vídeos curtos. A equipe do canal é a responsável pelos dados tratados pelo app InfoSnack (o “app”). Contato: maycrodriguess@gmail.com.

2. Que dados o app acessa

Quando um membro da equipe conecta uma conta oficial do InfoSnack a uma rede social, o app recebe da rede:

  • Perfil básico da conta: identificador, nome, nome de usuário e foto.
  • Credenciais de acesso: os tokens que a rede entrega para o app publicar em nome da conta.
  • Dados para publicar: o que a rede informa para o envio dar certo, como as opções de privacidade permitidas e o limite de duração do vídeo (TikTok) ou as páginas que a conta administra (Facebook).
  • Resultado das publicações: o link e o identificador de cada post feito pelo app.

O app não acessa mensagens, seguidores, curtidas, comentários, dados de quem assiste aos vídeos nem dados de pagamento.

3. Para que usamos

Só para publicar os vídeos que a equipe escolhe e mostrar o resultado no app. Não usamos esses dados para publicidade nem para criar perfis, e não os vendemos.

4. Onde ficam e como protegemos

  • Os dados ficam só no computador da equipe, em arquivos que apenas o usuário do sistema pode ler.
  • Não existe um servidor do InfoSnack: os dados não são enviados para nenhum lugar além das próprias redes.
  • A comunicação com as redes usa conexão criptografada (HTTPS).

5. Compartilhamento

Não compartilhamos dados com terceiros. As únicas exceções são a própria rede que recebe a publicação e os casos em que a lei obriga.

6. Por quanto tempo guardamos

O perfil e os tokens de uma conta ficam guardados enquanto ela estiver conectada e são apagados assim que ela é desconectada. O link de cada publicação fica junto do projeto do vídeo até o projeto ser apagado.

7. YouTube e Google

O app usa os Serviços de API do YouTube para enviar vídeos ao canal do InfoSnack. Ao conectar uma conta do YouTube, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google. Você pode revogar o acesso do app a qualquer momento na página de permissões da sua Conta do Google.

O uso que o app faz das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

8. TikTok, Meta e outras redes

No TikTok, o app usa o Login Kit e a Content Posting API, com as permissões user.info.basic, video.upload e video.publish. Na Meta (Instagram, Facebook e Threads), no X, no LinkedIn e nas demais redes, o app pede só as permissões necessárias para publicar e ler o perfil básico. Cada rede também trata dados segundo a própria política de privacidade.

9. Este site

Este site não usa cookies nem ferramentas de análise ou rastreamento e não coleta dados. Ele é hospedado no GitHub Pages, e o GitHub pode registrar dados técnicos de acesso, como o endereço IP, conforme a declaração de privacidade do GitHub.

10. Seus direitos (LGPD)

Pela Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você pode pedir para confirmar se tratamos seus dados, acessá-los, corrigi-los, apagá-los e revogar uma autorização. Escreva para maycrodriguess@gmail.com e respondemos em até 15 dias. Veja também Como excluir seus dados.

11. Mudanças

Podemos atualizar esta política. A data no topo da página mostra a versão em vigor.
